Trouver votre URL iCal sur Airbnb

  1. Connectez-vous sur airbnb.fr et passez en mode hôte
  2. Cliquez sur "Calendrier" dans le menu
  3. Sélectionnez le studio concerné
  4. Dans le panneau de droite, cliquez sur "Paramètres de disponibilité"
  5. Faites défiler jusqu'en bas → cliquez sur "Associer un autre calendrier"
  6. Cliquez sur "Me connecter à un autre site web"
  7. Votre URL iCal se trouve dans la section "Étape 1" — copiez-la en entier

⚠️ Chaque studio a sa propre URL iCal. Répétez l’opération pour chaque studio.
